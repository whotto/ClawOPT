# ClawOPT v1.2.2

修复三处「出问题时你看不出来」的行为。

## 长回复被截断却显示成正常完成

连接中断时，如果已经流出的内容超过 200 字，程序**不会**尝试补救，还会把这条回复标成已完成。也就是说：短回复断一截会自动补回来，长回复断流反而不管——而长回复才是你真正会被坑的场景。

现在只要没收到正常的结束信号，就一律回聊天记录里对账取完整版本；对账也拿不到时，会明确告诉你「这条回复可能没写完」，而不是让你以为它就是这么短。你主动点停止的情况不会误报。

## 群聊卡死后只能 /stop 才能恢复

某些操作（文档工具首次初始化最长 20 分钟、语音转写、图片生成）没有超时保护，一旦挂住，这个群的后续消息会一直被拒绝，且没有任何自救方式。

现在超过 15 分钟未结束会判定为卡死，新消息可以直接接管；正在跑的任务不会被强杀（它可能只是慢，杀掉会丢掉已经产生的回复）。被拒绝时也会告诉你上一轮已经跑了多少分钟，而不是一句冷冰冰的"进行中"。

## 失败时不吭声

- 群聊消息发送失败：输入内容会退回输入框，但不说为什么
- 附件上传失败：附件被丢掉，消息照发——你以为文件发出去了，对方什么也没收到
- 首屏聊天记录加载失败：界面变成空会话，看起来像记录丢了

三处现在统一在输入框上方给出可关闭的提示，说清楚发生了什么、能做什么。
