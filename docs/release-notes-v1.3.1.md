# v1.3.1 —— 运行时选择在界面上回显不出来

v1.3.0 的运行时下拉框**存进去了但读不回来**：名册写对了、引擎认了、
会话列表里也有了，但配置接口返回的 `agentRuntime` 是空的。

后果不是报错——下拉框会一直显示「OpenClaw（默认）」，
**哪怕这个 Agent 明明跑在 Claude Code 上**。用户改一次别的设置保存，
就把运行时悄悄改回默认了。

## 原因

那两处响应在**逐字段拷贝**运行时设置，而不是展开。我在数据源里加了新字段，
拷贝那一侧没跟着加——而逐字段拷贝在加字段时不会提醒你。

## 顺带加了一道守卫

新用例从 `readEffectiveAgentRuntimeSettings()` 的返回类型里**解析出字段名**，
再逐个检查响应组装处有没有引用。少带一个就红。

它防的不是这一个 bug，是**下次再加字段时同样忘记**。

## 验证

- `npm test`：**189 passed**
- 红证：把回显字段拿掉 → `configs 响应没有带上 agentRuntime —— 逐字段拷贝漏了它`
