# v1.10.0 —— 对话内核补齐、群协作升级与远程 Agent、工作区外围

这一版补完三块：单聊的完整交互、群协作编排与跨机远程 Agent、工作区与外围工具（终端 / 文件 / 语音 / 记忆 / MCP 服务）。

## 单聊

- **回复中继续输入会排队**，队列可取消、可「立即插入」打断当前回复先发这一条；被打断的那轮会明确标出来，不当作错误。
- **刷新、换标签页、断线重连都能接回**正在进行的回复，多标签页同步。
- **助手消息下方新增**：工具轨迹摘要卡（失败 / 中断标记、参数与结果预览）、任务计划卡、本轮工作区改动卡（N 个文件 +a −d）。点开是右侧 diff 面板，可懒加载差异并查看文件原文。
- **上下文占用与剩余**显示在输入框下方，接近上限时提示压缩；`/compact`、`/status`、`/usage` 直接在对话里给结构化结果（走各运行时自己的原生压缩）。
- **「/」命令面板**、引用回复、每会话草稿、输入法安全的回车、可拖拽输入框高度。
- **附件**：粘贴图片自动命名、同名去重、视频自动抽代表帧、每个附件可加说明。
- **会话组织**：分类的新建 / 改名 / 删除与挪动、置顶、最近、归档、只看人建的对话、管理员批量删除（部分失败逐个说明）。分类、置顶、归档按账号保存。
- **标题**：按第一条消息自动生成，可就地改名（手动名永远不会被自动或 Agent 覆盖）。支持导出 JSON / Markdown；支持分叉的运行时可从当前对话分叉。
- **全局搜索 Ctrl/Cmd+K**：空查询显示最近对话，输入即搜正文与标题，回车跳到命中消息并高亮。另有 Ctrl/Cmd+N 新建、Ctrl/Cmd+, 设置、Esc 关闭。
- **完成与审批提醒**：提示音、系统通知、侧栏未读点，可在设置里开关。
- **外部运行时单聊可显式放行指定工具**（如 Write / Edit）。不放行时按运行时自身的权限规则拒绝，**不使用跳过权限审批的开关**。
- 预览加固（HTML 沙箱、压缩包炸弹预检、表格后台解析）、首次使用引导提示，以及若干界面缺陷修复。

## 群协作

- **结构化 @**：参与者 ID 必须与正文里可见的 `@名字` 对得上；Agent 发送时集合必须完全一致，杜绝隐藏 @。
- **每个 Agent 一条持久化队列**：可见排队位置，发起人可撤回（所有目标仍在排队才可撤），撤回会连带作废受影响的摘要。
- **交接深度由服务端逐跳签发**，永不采信 Agent 上报。被深度上限截断时留一张「停止链」卡片，管理员点「继续」放行一跳；这一跳走持久化的 outbox / inbox，断连时标记为「结果未知」而不是盲目重试。
- **发起人授权沿链传播**：成员在群里发消息，只会叫起分配给他的 Agent；链式转交的每一跳也按发起人的授权判定。
- **滚动群摘要**：可配摘要模型与轮次，六段结构、注入加固，带乐观锁与租约隔离，可手工编辑。未配置摘要模型不挡发送。
- **审批只发给 Agent 的主人，澄清只发给群管理员**，超时即拒绝，断线重连后恢复倒计时。
- **会话隔离**：清空、删除、换工作区前先封禁旧会话，正在收尾的运行写不进新群。运行超时按事件续期 + 总预算。
- **群共享工作区**：管理员可浏览与编辑，每轮运行的文件改动挂在该条回复下。
- **群附件**：配额、限流、可续传分块上传，服务端重绑路径。
- **群级异步委派**：`/delegate @成员 任务`，结果作为自主后续一跳交还。

## 远程 Agent（跨机协作）

- 另一台 ClawOPT 上的运行时可以**接进本机的群**：主人批准配对，双密钥（配对请求密钥 + 一次性入场票据），连接凭据只存哈希。
- 运行协议带版本号、事件编号与逐帧确认、单帧在途背压、密钥脱敏；断连或超时标记为「结果未知」并交给交接状态机。
- **远程工作区按运行签发令牌**：有效期短、次数上限、跑完即吊销，路径闸门与群工作区编辑器同一套。
- **访客页** `/share/rooms/:邀请码`：无账号访客可加入、发言、上传，也可以把自己的 Agent 配对进来。访客的叫起按签发邀请码的人的授权判定。

## 工作区与外围

- **网页终端**：仅超级管理员，一次性票据（不把令牌放 URL），断线可接回原会话，shell 白名单，关闭即回收整个进程树。
- **文件管理器**：本地 / SSH / Docker 后端，路径闸门 + 授权双重校验，分块续传，版本库状态标注，编辑器带版本校验。SSH 的主机密钥检查不可关闭。
- **语音**：TTS / STT 服务商适配层（密钥服务端封存），聊天框「按住说话」与自动朗读开关。本地离线转写模型未内置（体积与内存不适合 2GB 生产机），页面内说明替代方案。
- **主题**：明暗 / 跟随系统、强调色、文字色、字号、背景图，挂载前生效不闪屏。
- **ClawOPT 作为 MCP 服务**：把会话、工作流、看板、记忆作为工具提供给外部运行时，**每次运行单独签发范围令牌**（2 小时有效、运行结束即吊销、操作白名单、只收本机回环）。默认关闭，按运行时开启。
- **记忆服务**：独立 SQLite 的类型化记忆卡片，服务端生成键、版本化、三级作用域（Agent / 群 / 会话），意图闸门识别否定句，按 token 预算召回；列表与图谱两种视图。
- **成长轨迹图**、**性能监控页**。
