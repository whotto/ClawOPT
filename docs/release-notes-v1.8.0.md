# v1.8.0 —— 地基重构 + 外部 Agent 进群

这一版有两部分：自 v1.7.0 以来已在 main 上的外部 Agent 协作能力，以及一次**不改行为**的结构重构，为接下来接入全部外部运行时、工作流和多人协作打地基。

## 一、外部 Agent 与 OpenClaw 角色在同一个群里协作

- **双向协作**：外部 Agent（Claude Code）与 OpenClaw 角色可以互相 @ 转交任务，链式转发与 OpenClaw 那条路共享深度上限和成员锁。
  - 外部成员拿到完整群上下文：名册、群设定、最近历史、@ 协议。
- **每成员一把锁**：一个成员在忙不再挡住整个群。此前这把锁在 HTTP 层被整个抵消，是空转的。
- **成员运行时可在界面配置**：新增 `GET /api/external-runtimes`，按真实二进制探测结果决定能不能选，并显示探测时间。
- **修复数据丢失**：此前改群名或调成员顺序，会让所有外部成员退回 OpenClaw、外部会话全部丢失。现在改为增量更新。
- **运行时不变量**：机器上的状态坏了（二进制丢失、会话不可续）会变成看得见的诊断项。
- **长 prompt 走 stdin**：绕开 `ARG_MAX`，避免「成员不说话」且无报错。
- **视觉语言**：重做设计 token，交互色与运行时身份色分离；键盘焦点可见、减少动态效果、中文字体栈。

## 二、地基重构（行为不变）

### 后端：1.4 万行单文件拆成模块

`backend/src/index.ts` 从约 14,200 行降到 13 行，只负责启动。代码按职责分进这些目录：

- `bootstrap/`：组装、中间件与路由顺序、生命周期；
- `core/`：数据库、鉴权、文件闸门、配置、错误码、事件总线；
- `openclaw/`：网关客户端、`openclaw.json` 读写、版本探测；
- `runtime/`：外部 Agent 运行时；
- `control/`：控制面路由与服务；
- `workspace/`：上传、下载、预览；
- `collab/sessions/`（单聊）与 `collab/rooms/`（群聊）。

验证：
- 路由清单逐条比对，与 v1.7.0 之后的 main **完全一致**，只多了两个健康探针。
- 路由注册顺序由用例对照清单校验。
- 编译产物实跑：前端静态资源、预设库、版本信息、深链回退全部正常。

新增基础设施（本版只落地、带测试，后续阶段接入）：

- **SafeFileStore**：按路径排队、原子写、备份、多文件事务（按序加锁，失败回滚），以及跨进程文件锁（OpenClaw 网关也会写同一批文件）。
- **配置版本号**：内容哈希含密钥值，陈旧保存返回 `412 REVISION_CONFLICT` 并附当前状态。
- **业务事件总线**：每个消费者故障隔离。
- **健康探针**：`/livez`（始终 200）、`/readyz`（数据库就绪且已监听才 200）。
- **优雅停机注册表**、**启动一次性任务登记表**（执行记录落盘，状态损坏就拒跑）。
- **OpenAPI 生成**：`npm run openapi:generate`，从路由登记表生成。
- **模块边界检查**：模块之间只经 barrel 导入，`core/` 不得依赖业务模块。`npm run harness:check` 一个入口跑三语、边界、预设三道门。

### 前端：路由 + API 层 + 大组件拆分

- **每个视图都有地址**：
  - 可用地址：`/login`、`/chat/:sessionId`、`/groups/:groupId`、`/settings/:tab`；
  - 刷新不丢、前进后退可用；
  - 旧的 `#settings/...` 书签会自动换成新路径。
- **登录**：未登录时进入 `/login`，登录后回到原来要去的页面；未登录期间不再发出一串 401 请求。
- **API 层**：所有请求集中到 `src/api/`，组件里不再直接写 `fetch`。
- **大组件拆分**：
  - `SettingsView`（6,842 行）、`UnifiedChatView`（3,933 行）、`Sidebar`（2,630 行）拆成页面、功能块与侧栏子组件；
  - 除 `MessageBubble` 外单文件不超过 800 行。`MessageBubble` 的展开收起逻辑在一个闭包里，刻意保持完整。
- **验证**：
  - 与重构前在 1440px / 390px 下逐屏对比 DOM 与像素，34 组截图一致；
  - 多 Agent 群聊直播回放无「长 → 短」回退。
