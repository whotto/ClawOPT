# v1.9.0 —— 全部外部 Agent、工作流、控制面与多用户

这一版把 ClawOPT 从「OpenClaw 客户端」扩成多运行时的协作平台。**升级前请先读「行为变化」一节**：登录与权限的默认规则变了。

## 行为变化（升级必读）

- **不再有默认密码。**
  - 此前开启登录且仍用默认口令的主机：首次启动会生成一个 `admin` 账号，必须先改密码，改之前其余接口都返回 403。
  - 登录关闭且从未设过口令的主机：不生成账号；之后要开启登录，必须先设口令。
- **写操作需要管理员角色。**
  - 网关、快捷命令、角色、模型等写接口原来任何登录用户都能调，现在要 admin 及以上。
  - 新建、编辑、删除单聊会话（会创建或删除 OpenClaw Agent）也改为管理员。
- **成员（member）只看得到被授权的 Agent。**
  - 覆盖单聊、群聊、历史、文件预览下载、上传、工作流、看板、实时通道。
  - 未授权一律 403；成员在群里 @ 未授权的 Agent 只记文字，不唤醒。
- **请求体上限**从 100KB 提到 4MB（身份文件、头像、工作流定义）；本地模型代理单独 64MB。
- **删除了 `GET /api/external-runtimes`**：它此前未登录即可访问。改用 `GET /api/runtime/member-runtimes`（需登录）。
- **停止、删除、重置群聊时会一并终止正在运行的外部 Agent**，此前停止按钮停不住 Claude Code。

## 外部 Agent：七个运行时全部接入

- **七个运行时**：Claude Code、Codex、Pi、Grok、OpenCode、DeepSeek Harness（DSH）、Hermes Agent 可在单聊、群聊、工作流里使用。
- **两种模式**：
  - **全局**：CLI 用自己的登录与模型；
  - **托管**：在 ClawOPT 里选服务商和模型，CLI 只连本机代理，上游密钥不写进任何 CLI 配置文件。
- **本地模型代理**：Anthropic Messages / Chat Completions / Responses 三种协议互转（含流式），DeepSeek 系推理内容回传，Codex 工具命名空间展开，请求体瘦身。出站地址解析后校验并钉住 IP。
- **Agent 运行时管理页**（团队区，管理员）：
  - 检测、安装、升级、卸载，以及自动升级（空闲 60 秒且无运行时才升级）；
  - 编辑原生偏好与配置文件（密钥不显示）；
  - MCP 管理与运行前健康隔离，坏掉的 MCP 只从本次运行剔除；
  - 失败时可一键让 AI 诊断（预填，不自动发送）。
- **远程 OpenClaw 成员**：把另一台 OpenClaw 网关上的 Agent 拉进群。令牌只写不读，私有地址需显式开「可信局域网」。
- **真实审批**：Pi、Hermes 的审批请求出现在待办中心和聊天输入框上方，可选「允许一次 / 本会话 / 总是 / 拒绝」。
- **群成员运行时选择器**，以及直接用外部运行时开单聊。
- **运行目录**随会话、成员删除回收，并按闲置天数定期清理。
- **修复**：两路输出同一段文本时出现重复（如「okok」）。
- **修复**：没配工作目录的外部成员不再在后端进程目录里运行，改为本群工作区。

## 运行协调器与实时通道

- **统一协调器**：所有运行（OpenClaw 单聊、外部成员、工作流节点、看板派活）走同一个协调器。队列、陈旧事件丢弃、中止、按调用去重的用量、工具调用落库、终态顺序都只实现一处。
- **`/ws` WebSocket 通道**：
  - 与 HTTP 同一套 cookie 鉴权，按主题授权；
  - 心跳时重验，用户被停用或会话吊销即断开；
  - 默认仍用 SSE，可在设置里切到 WS。
- **业务事件**由协调器统一发出：`chat.run.*`、`chat.tool.*`、`chat.approval.*`。

## 工作流、计划、Webhook、看板

- **可视化工作流**：
  - 条件分支、失败路由、全部 / 任一汇合、有上限的反馈循环、审批节点、运行预算；
  - 冻结快照与判定证据回放、从节点重跑；
  - 两阶段导入导出，可随 `.clawpack` 打包；
  - 节点可选 OpenClaw 角色或任一外部运行时。
- **定时计划**（标准 cron、时区、夏令时安全，错过与重叠都跳过并留日志）与**签名入站钩子**（HMAC + 5 分钟时间窗 + 防重放）。
- **出站 Webhook**：持久化 outbox，按端点保序重试，时间戳 HMAC 签名，SSRF 防护并钉 IP，内置本机测试收件箱。
- **原生看板**：状态流转服务端校验，派活交给协调器执行。

## OpenClaw 控制面

- **引擎能力管理**：定时任务、频道、技能、MCP、插件，底层调用 OpenClaw CLI 或网关。
- **模型目录缓存**：空结果算失败，移除需确认，保护默认模型，可一步撤销。另有别名、可见性、上下文长度覆盖、服务商审计日志。
- **配置编辑器版本号**：外部改过时返回 412 并显示最新值。
- **Agent 相关**：
  - 克隆时剥离频道绑定与凭据；
  - 头像；
  - 7 份身份文件编辑器（跨进程文件锁 + 版本校验）；
  - 写入审批：Agent 改记忆 / 技能先暂存，审阅 diff 后生效。
- **用量、日志、网关状态页。**
- **多用户**：
  - 角色分 super_admin、admin、member，按用户分配 Agent，外部运行时也可以授权；
  - 登录 IP 锁定与解锁；最后一个超级管理员不可降级或删除；
  - 界面按服务端下发的能力清单显示。
- **修复**：`GET /api/endpoints` 回传明文 apiKey；设置页每次打开都回写模型故障转移配置；侧栏收藏加载时回写且会删掉共享收藏。
