# ClawOPT v1.2.0

**这一版是安全与可靠性版本，建议尽快升级。** 内容来自一次五维度全面审计（安全、功能、代码质量、原创性、运维）。

## 安全

**鉴权从「逐路由手挂」改为「默认全保护」。** 审计实测：108 个路由只有 15 个挂了鉴权，数据面（建会话、发消息、删会话、建群、上传文件）全部无需凭据即可调用——即使开启了登录，登录页也只挡住了「改配置」和「装包」。现在 `/api/*` 默认拦截，白名单只放行登录与版本查询；`/openclaw` 与 `/uploads` 一并纳入。

**登录令牌换成真正的会话令牌。** 旧实现是 `sha256(口令 + 写死在开源代码里的固定盐)`——默认口令 `123456` 意味着令牌可被离线算出，且泄露一次永久有效。现在是 32 字节随机令牌，服务端存储、30 天过期、可吊销，改口令即作废全部会话。口令改用 scrypt 加随机盐存储，**升级时自动迁移，无需手动操作**。

**Web 端令牌改由 httpOnly cookie 承载**，不再存 localStorage（XSS 可读）、不再进查询串（会落进访问日志与浏览器历史）。命令行的 `X-ClawOPT-Auth-Token` 请求头通道不变。

**任意文件读取（三个预览入口）。** 上一版修了下载与静态挂载，但 `preview` / `preview-data` / `html-preview` 走的是另一条路径，实测可读 `~/.ssh/id_rsa` 与 `openclaw.json` 里的模型 API key。现在所有按路径出文件的入口统一过白名单闸门，HTML 预览的子资源不得逃出入口目录。

**导入包的解压炸弹。** 实测一个 1MB 的包可解出 1GB。现在解压有输出上限，并对单文件、总量、文件数分别设限。

**XSS。** 聊天里的嵌入 iframe 去掉 `allow-same-origin`（它与 `allow-scripts` 并存时沙箱等于自我解除）；HTML 预览接入 DOMPurify（原来只删标签不删 `onerror`/`javascript:` 这类属性）。

## 可靠性

**发布产物由 CI 构建。** `deploy-release.sh` 一直在找预构建产物，但此前没有任何流程生成它，于是每台机器都回退到本地全量构建——2GB 主机会被前端构建打到失去响应。现在打 tag 时 CI 构建并上传，生产机只解压。可用内存低于 1200MB 且无产物时，部署脚本直接拒绝本地构建而不是硬跑。

**按发布 tag 部署，不再部署 main。** 此前"用户看到的版本号"与"实际运行的代码"可以不一致。开发机跟随 main 请设 `CLAWOPT_TARGET_REF=main`。

**升级失败自动回滚**到升级前的提交并用旧代码重新部署。

**SQLite 开启 WAL**，新增 `scripts/backup.sh`：在线备份数据库、打包智能体工作区、`openclaw.json` 脱敏后留档，滚动保留 7 份。建议配 cron 每日运行。

**装配失败不再显示成功。** 此前 OpenClaw 未安装等情况下装配会静默"成功"，界面全绿而智能体是空壳；失败还会留下半成品导致重试被跳过。现在错误如实上报，失败可直接重试。

## 升级后注意

- 设置页不再回显已保存的凭据（网关 token、网关密码、登录密码），显示"已配置（留空表示不修改）"。这是预期变化，不是配置丢失。
- 请**硬刷新浏览器**（`Cmd+Shift+R` / `Ctrl+F5`），旧页面会持有已失效的令牌。
- 浏览器插件未启用时，升级末尾的浏览器预热判为"已跳过"而非失败。
