# ClawOPT v1.2.1

工程质量版本，不含破坏性改动。

## 测试

此前仓库没有任何行为测试，`npm run test` 只做类型检查。本版引入 vitest 并补了 50 个用例，优先覆盖「一旦回归不会报错、只会静默出错」的地方：登录凭据与会话令牌、`.clawpack` 包解析与路径闸门、可服务路径白名单、上游消息解包、聊天历史对账。

守卫的有效性做过验证：把路径闸门的 realpath 判定改回有缺陷的写法，只有「符号链接逃逸」一条用例变红，还原后全绿。没验过会不会红的门，不算门。

## 清理与修复

- 删除 `frontend/src/pages_old/`（502 行死代码，零引用却每次构建都参与类型检查）。
- 接回 `scripts/reconcile-openclaw-runtime.mjs`：这个 692 行的脚本此前没有任何调用点，而项目文档一直把它做的三件事（对齐 systemd 单元的可执行路径、批准本机 device repair、验证浏览器运行时）写成升级成功的必要条件。现在它在升级的 OpenClaw 重启阶段真正运行，失败只告警不阻断。
- `.clawpack` 的错误信息补上错误码：此前日志里只看到出问题的路径，看不出是哪一类拒绝。
