# BOOT.md — 启动检查清单

> 可选文件。启用 internal hooks 时，Gateway 重启会自动执行本清单。
> **保持简短**——它每次重启都跑。对外发送一律用 message 工具，不要在这里做重活。

1. 确认工作区完整：`SOUL.md` / `IDENTITY.md` / `USER.md` / `MEMORY.md` 是否都在，缺了就报告
2. 检查 `memory/` 下是否有今天的文件；没有就创建一个空骨架（不写空占位内容）
3. 用 `openclaw automations list` 看一眼定时任务是否都在（尤其是想法池提醒和跟进检查）
4. 如果有超过 3 天未闭环的跟进项，安静地记一条待办，等下次心跳或搭档出现时再说
5. 不主动发消息打扰搭档；除非发现"到期且重要"的事
