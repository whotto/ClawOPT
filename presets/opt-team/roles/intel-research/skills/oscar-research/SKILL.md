# OSCAR 系统调研 · oscar-research

> 把一个说不清的复杂问题，拆成一份可检索、可验证、可交付的信息作业。
> **全程不给结论，只给经过验证的信息和可信度判断。**

## 硬约束

1. **O→S→C→A1→R1 严格按序，不许跳步。未满足本步退出条件，不得进入下一步。**
2. **A2⇄R2 循环，不是两个先后步骤。** 循环上限 4 轮，收敛不了就如实说哪块收敛不了。
3. **不给"能做/不能做"。** 交付信息地图与可信度，判断权在用户。
4. **搜不到标"未找到"**，不编、不推、不用行业常识填。
5. **每条信息三标签**：来源 + 年份 + 可信度。

## 权限与数据边界

| 项 | 边界 |
|----|------|
| 读 | 本工作区 `memory/`、`references/`；联网公开信息 |
| 写 | 仅本工作区 `memory/`；**不写入任何其他 Agent 的工作区** |
| 外发 | 无。不发邮件、不发帖、不提交表单 |
| 敏感数据 | **不把搭档的内部项目名、客户名、未公开数据打进搜索查询串**——查询串会离开本机 |
| 付费源 | 涉及付费数据源必须先问搭档 |
| 升权 | 不需要 `exec`、不需要 sudo、不安装任何包 |
| 大文件 | `references/oscar-data-pack.md` 约 76KB，**禁止全量读取**，只用 Grep 精准定位 |

## 何时使用 / 何时不用

| 场景 | 用不用 |
|------|--------|
| "预制菜赛道现在怎么样" | ✅ 用 |
| "这个加盟项目靠不靠谱" | ✅ 用 |
| "帮我把这几家竞品扒一遍" | ✅ 用 |
| "查一下宁德时代去年营收" | ❌ → `point-intel` |
| "我该不该做这个决定" | ❌ → 科学决策 `roi-deep-dive`（本调研可作其输入） |
| "用户到底要什么" | ❌ → 商业洞察 `jtbd-demand` |

**降级信号**：走到 R1 发现核心其实就两三个数据点 → 主动说"其实核心信息就这两三个，咱们先把这几个查清楚？"转 `point-intel`。

## 输入输出契约

**输入**：一句模糊的复杂问题 + 用途（要拿这份调研做什么决定）
**输出**：`assets/oscar-report.md` 格式的报告。必含：调研目标与用途 / 不看清单 / 一页纸速览 / 分维度详情（已确认·存在分歧·未找到）/ 对象清单与采样说明 / 反面证据 / 推算部分 / 信息缺口地图 / 信源清单
**中间产物**：R1 信息点清单（可逐条交给 `point-intel` 执行）
**上游**：`team-health-diagnosis` 需要外部基线时调用本技能
**下游**：`roi-deep-dive` 的关键变量输入 / `five-steps-quick` 的画布素材 / `idea-management` 的想法池补充
**串联示例**：`oscar-research`(O→R1) → `point-intel` ×N → `oscar-research`(A2/R2→报告) → `roi-deep-dive`

## 流程

### O · 明确目标

**必问三件事**（一次问完，不要挤牙膏）：

> "开工前对三件事：
> ① 你**要拿这份调研做什么决定**？（要不要进 / 怎么进 / 定价 / 找差异点）
> ② 有没有**已经知道的**，我就不重复搜了？
> ③ 你要的是**先看个全貌**，还是**几个关键问题挖到底**？"

**输出**：一句话调研目标 + 用途。

> 示例：目标 = 判断"社区宠物医院"在二线城市是否存在结构性机会。用途 = 决定要不要投入 3 个月做小范围试点。

**退出条件**：用户确认这句话没跑偏。
**常见失败**：用户说"帮我调研一下预制菜"就直接开搜，三天后交出 50 页什么都有、什么都不解决的报告。**O 步就是防这个。**

### S · 拆解范围

拆成 4-7 个维度，并**明确说出不看什么**。

| 维度 | 什么时候要 |
|------|-----------|
| 市场规模与增速 | 判断天花板 |
| 竞争格局 | 判断能不能挤进去 |
| 需求侧特征 | 判断客户是谁、买不买 |
| 供给侧与成本结构 | 判断单位经济模型 |
| 政策与监管 | 强监管行业必看 |
| 技术/产品成熟度 | 技术驱动型必看 |
| 渠道与获客 | 判断怎么卖 |
| **典型失败案例** | **最容易被漏掉、性价比最高的一维** |

**边界声明（必须写）**：

> "本次**不看**：海外市场、B 端业务线、2020 年前的历史沿革。原因：与'二线城市社区店'的决策无关。"

**退出条件**：维度清单 + 不看清单，用户确认。

### C · 罗列对象

把维度落到**有名有姓的对象**上：公司/品牌（列名字，不写"头部品牌"）、地区（列城市，不写"二线城市"）、时间段（列年份）、人群（列画像，不写"年轻人"）。

**采样纪律**：竞品至少覆盖 **头部 2 家 + 腰部 2 家 + 死掉 1 家**。只看头部是幸存者偏差的标准犯法现场。

**退出条件**：对象清单可数、可查、无"等等""之类的"。

### A1 · 制定方案

对每个「维度 × 对象」说清**怎么查、查到什么程度**：

```
维度：竞争格局
对象：A/B/C/D/E 五家
方法：① 官网与公众号扒产品线与定价 ② 招聘 JD 反推团队规模与重点
      ③ 工商信息看融资与股权 ④ 点评平台抓门店数与评分分布
深度：拿到门店数、价格带、融资阶段三项即可，不做财务建模
```

**退出条件**：每个维度都有方法和深度，没有"再看看"这种空条目。

### R1 · 拆分信息点（OSCAR 的胜负手）

把方案拆成**可勾选的信息点清单**。每条必须**可检索、可判真假**。

| ❌ 不合格 | ✅ 合格 |
|----------|--------|
| 了解竞争格局 | A 品牌 2025 年末直营门店数 |
| 看看政策 | 2024 年后出台的宠物诊疗机构准入许可条件 |
| 分析用户需求 | 单次宠物诊疗客单价区间（一线 vs 二线，2024-2025） |

**清单格式**：

| # | 维度 | 信息点（可判真假） | 优先级 | 状态 |
|---|------|-------------------|--------|------|
| 1 | 市场规模 | 2025 年宠物医疗市场规模（零售口径） | P0 | 待查 |

**优先级**：P0 = 缺了整份调研没意义；P1 = 影响判断精度；P2 = 锦上添花。

**退出条件**：每条都能被"搜到/搜不到"二值回答，且 **P0 项 ≤10 条**。
**超过 10 条 P0 说明 O 步没收敛** → 回 O 重新对目标，不许硬着头皮往下搜。

### A2 · 搜索证据

按 R1 清单**逐条**搜，每条执行 `point-intel` 的饱和式六项指标（关键词 ≥3 组 / 中英双语 / 来源 ≥3 类 / 必搜反面证据 / 上游追溯 / 收敛停止）。

**边搜边填，不要最后回忆**：

| # | 信息点 | 结果 | 来源 | 年份 | 可信度 | 备注 |
|---|--------|------|------|------|--------|------|
| 1 | 市场规模 | 1,580 亿 | 白皮书链接 | 2026 | ✅A | 零售口径 |
| 2 | A 品牌门店数 | **未找到** | — | — | ❌D | 官网不披露；建议查招股书 |

**纪律**：搜完一条勾一条。**不许跳过难搜的条目**——难搜的往往正是 P0。
**退出条件**：R1 清单每条都有状态，无悬空项。

### R2 · 归因评估

**四问**：

1. **P0 覆盖率多少？** 低于 70% 不能进报告 → 回 A2
2. **有没有互相矛盾的证据？** 有 → 追口径、追上游、追年份；仍解释不了则并列呈现
3. **有没有信息茧房？** 搜到的全是正面 → 强制补一轮反面证据
4. **哪些结论建立在单一来源上？** 全部标注出来，不许混在 A 级里

**收敛判定**：新一轮 A2 不再改变任何一条 P0 的结论 → 收敛。
**退出条件**：收敛，或已达 4 轮上限并如实说明哪块收敛不了。

## 自检闸门

进报告前逐条打勾，**不过就回退到对应步骤**：

- [ ] O 的调研目标和用途，在报告开头原样写出来了　→ 不过回 O
- [ ] S 的"不看清单"写进报告了　→ 不过回 S
- [ ] 对象清单含**至少 1 家已退出**的　→ 不过回 C
- [ ] R1 清单每条都有状态（已查/未找到），无悬空项　→ 不过回 A2
- [ ] P0 覆盖率 ≥70%，未覆盖的已进缺口清单　→ 不过回 A2
- [ ] 每条信息有来源 + 年份 + 可信度　→ 不过回 A2
- [ ] 关键结论有 ≥2 个独立来源，同源风险已标　→ 不过回 R2
- [ ] 搜过反面证据和失败案例　→ 不过回 A2
- [ ] 推算部分显式标注"（推测，依据：……）"　→ 不过回 R2
- [ ] **全文没有"建议/应该/值得做/不值得做/综合来看"**　→ 不过，改写

## 量化验收指标

| 指标 | 门槛 |
|------|------|
| 维度数 | 4-7 个，且含"典型失败案例"一维 |
| P0 信息点数 | ≤10 条 |
| P0 覆盖率 | ≥70% |
| 竞品采样 | 头部 ≥2 + 腰部 ≥2 + **已退出 ≥1** |
| 每条信息的三标签完整率 | 100% |
| 反面证据轮次 | ≥1 轮 |
| A2⇄R2 循环 | ≤4 轮 |
| 报告中建议句式出现次数 | **0** |
| 未找到项的替代渠道覆盖率 | 100% |

## 常见失败模式

| 失败 | 表现 | 怎么避免 |
|------|------|---------|
| 跳过 O 直接搜 | 交出什么都有、什么都不解决的报告 | O 的退出条件是硬门槛 |
| R1 写成大纲 | "了解竞争格局"这种不可检索的条目 | 每条必须可判真假 |
| P0 泛滥 | 列了 30 条 P0 | 超 10 条说明目标没收敛，回 O |
| 只搜活着的 | 竞品清单里没有一家死掉的 | C 步强制"已退出 ≥1" |
| A2 跳难条 | 好搜的都搜了，难搜的悄悄略过 | 逐条勾选，未找到也要记录 |
| 无限循环 | 搜了八轮还在搜 | 上限 4 轮，收敛不了如实说 |
| 报告给结论 | 末尾写"综合来看这个赛道值得进" | 建议句式零容忍 |
| 共性靠感觉 | "行业普遍……" | 必须给分母和比例 |
| 数据包吃爆上下文 | 全量读 76KB 的 data-pack | 只用 Grep 精准定位 |

## 降级与失败路径

| 情况 | 做法 |
|------|------|
| **P0 覆盖率上不去** | 报告照出，但在开头显著位置标"本次 P0 覆盖率仅 X%，以下结论的适用性受限"，并把缺口地图前置 |
| **A2⇄R2 4 轮仍不收敛** | 停。如实说"这几块公开渠道收敛不了"，给替代获取方案（行业协会年鉴 / 招股书 / 供应链访谈 / 政府信息公开申请） |
| **时间不够** | 优先保 P0 与"典型失败案例"两项，P1/P2 标"未展开"。**绝不为赶时间降低标注标准** |
| **发现问题其实是决策问题** | 停下来说："这个问题的核心是要不要做，不是信息不够。要不要拉科学决策一起拆？" |
| **发现是单点问题** | 降级到 `point-intel`，不硬走完八步 |

## 爆炸式补充模式（可选切换）

用户问的是"**大家都是怎么做的**""**成功的共性是什么**"这类**规律型**问题时，在 A2 阶段切换：

1. **不求深，求多**：展开 15-30 个同类案例，每个只抓 3-5 个结构化字段
2. **字段先定死**：如 `品牌｜起步城市｜起步年份｜首个产品｜定价带｜当前状态`
3. **提炼共性**：**≥60%** 的案例共有的特征才叫规律，低于此只叫现象
4. **必须包含失败案例**：只统计活着的品牌 = 幸存者偏差
5. **输出**：案例表 + 3-5 条共性规律 + **每条规律的反例**

**规律的表述纪律**：写"30 个案例里 21 个是从单城密集开店起步（70%）"，不写"行业普遍从单城起步"。

## 执行留痕与记忆写回

**留痕（可审计）**：报告须保留 R1 清单最终状态 + 每条的检索轮次与命中来源，任何人可按图复现这次调研。

**写回 `memory/YYYY-MM-DD.md`**：

1. O 的调研目标与用途
2. S 的维度清单与不看清单
3. R1 清单最终状态（哪些查到、哪些没查到）
4. 关键信息与来源
5. **未收敛的部分与替代获取方案**
6. 信源表现 → 累积进 `MEMORY.md` 的可信度校准记录

**技能记忆（L4）触发**：本次调研若用了 ≥5 次工具调用且摸索出了新的检索路径（例如"某类数据从招聘 JD 反推最快"），按 `reference/EVOLUTION.md` 沉淀候选技能到 `skills/_pending/`。

可信度分级完整判据见 `reference/credibility-standards.md`。
