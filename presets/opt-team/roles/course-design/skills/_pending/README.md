# _pending/ — 候选技能待审队列

Agent 自己沉淀出的新技能**先进这里**，不直接进 `skills/`。规则见 `reference/EVOLUTION.md`。

- 搭档批准 → 移入 `skills/<name>/`，`metadata.version` 从 `"0.1"` 起
- 搭档否决 → 移入 `_rejected/` 并记下否决理由（下次别再提同一个）
- 超过 30 天没处理 → 自动降级到 `_rejected/`，心跳时说一句

**为什么必须有这道闸门**：技能文件会被载入模型上下文并指导行为。允许自由写技能，等于把一次被注入污染的会话升级成写在自己工作区里、看起来完全合法的持久化后门。Hermes 有容器强化和预执行扫描兜底所以敢默认放开，OpenClaw 没有——**没有沙箱就必须有审批。**
