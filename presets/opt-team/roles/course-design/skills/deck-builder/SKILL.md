# 课件构建 · deck-builder

> 课件不是把讲稿贴到屏幕上。屏幕上的每一个字，都在跟讲师抢学员的注意力。
> 单页只讲一件事，是这条技能唯一的最高原则。

## 硬约束

1. **单页一件事。** 一页只承载一个概念、一个对比或一个动作。放不下就拆页，**不许缩小字号硬塞**。
2. **正文字号 ≥24px，标题 ≥40px。** 教室最后一排看不清的页，等于没做。
3. **屏幕上不写讲稿。** 讲师要说的话进 `<aside class="notes">` 演讲者备注，页面上只留关键词、数字、图。**单页正文超过 60 字直接拆页。**
4. **不生成插图。** 本技能没有生图能力。需要图就用内联 SVG 或 `mermaid-visual` 的产物，**不要用占位图或 AI 味的图标堆砌凑数**。
5. **交付前必须自己打开数一遍页数与溢出。** 未做过溢出检查不得交付。未满足本步退出条件，不得进入下一步。

## 权限与数据边界

| 项 | 边界 |
|----|------|
| 读 | 本工作区 `memory/`、课程物料；搭档指定的素材目录 |
| 写 | 课件目录（`memory/decks/<课程名>/` 或搭档指定路径）；**不写入任何其他 Agent 的工作区** |
| 外发 | 无。不上传课件到任何在线演示平台 |
| 敏感数据 | 学员名单、客户内部数据不进课件 —— 课件会被拍照转发 |
| 升权 | 仅一次性下载 Reveal.js 静态资源；不装全局包、不 sudo、不改系统配置 |

## 何时使用 / 何时不用

| 场景 | 用不用 |
|------|--------|
| "把这份大纲做成能放的课件" | ✅ 用 |
| "我下周要上台讲这个" | ✅ 用 |
| "做个路演材料" | ✅ 用 |
| "我要一个 .pptx 能自己改" | ❌ 本技能出 HTML，做不了可编辑 pptx，先说清楚 |
| "先把课程内容设计出来" | ❌ → `course-material-pack` |
| "画一张流程图" | ❌ → `mermaid-visual` |
| "这段文案太 AI 了" | ❌ → `human-writing` |

**降级信号**：搭档其实只要一份能发群里的材料，不上台讲 → 别做课件，交 Markdown 文档更好用。

## 输入输出契约

**输入**：课程大纲或讲稿 + 时长 + 场地条件（投影比例、有没有网）
**输出**：`<deck>/index.html`（单文件可放）+ `outline.md`（页面清单）+ 可选 `dist/`（Reveal.js 离线副本）
**上游**：`course-material-pack` 的课程大纲；`mermaid-visual` 的图；`human-writing` 过完的文案
**下游**：讲师上台；`memory/decks/` 留档复用
**串联示例**：`course-material-pack` → `human-writing` → `mermaid-visual` → `deck-builder`

## 流程

### Step 1 · 定页数预算

**每分钟 0.8-1.2 页**是安全区间。60 分钟的课，48-72 页。

先按这个算出预算，再看大纲能不能装下。装不下说明内容超时，回去砍内容，**不要靠加快语速解决**。

**退出条件**：页数预算算出来，且与大纲的模块数对得上。**未满足本步退出条件，不得进入下一步。**
**常见失败**：先做完 120 页才发现只有 60 分钟。

### Step 2 · 排页面清单

先写 `outline.md`，一行一页：页码 / 这页讲什么 / 页面类型 / 讲师要说的一句话。

七种页型够用了：

| 页型 | 用途 | 页面上放什么 |
|------|------|-------------|
| 封面 | 开场 | 课程名 + 讲师 + 日期 |
| 章节页 | 分段 | 一个大字 + 一句话 |
| 概念页 | 讲一个点 | 一句话 + 三个关键词 |
| 数字页 | 给冲击 | 一个大数字 + 一行出处 |
| 对比页 | 讲差别 | 左右两栏，各 ≤3 行 |
| 图页 | 讲结构 | 一张图 + 一句图注 |
| 动作页 | 让学员动手 | 任务 + 时间 + 交付物 |

**退出条件**：清单页数 = 预算页数 ±10%，且每页只有一件事。
**常见失败**：直接开写 HTML，写到一半发现结构不对，整份返工。

### Step 3 · 建工程

```bash
mkdir -p <deck>/{images,dist}
# 离线优先：一次性取 Reveal.js 静态资源
curl -fsSL -o /tmp/reveal.tgz https://registry.npmjs.org/reveal.js/-/reveal.js-5.2.1.tgz \
  && tar -xzf /tmp/reveal.tgz -C /tmp && cp -r /tmp/package/dist /tmp/package/plugin <deck>/
```

拿不到就退到 CDN 引用版，并在交付时**明确告诉搭档现场必须有网**。

**退出条件**：`index.html` 能在浏览器打开并翻页，或已明确记录降级方式。

### Step 4 · 填内容

- 正文 ≥24px，标题 ≥40px，行距 1.4 以上
- 一页正文 ≤60 字，超了拆页
- 分步揭示用 `class="fragment"`，一次只出现一个要点
- 讲师的话全部进 `<aside class="notes">`
- 图用内联 SVG 或 Mermaid 产物，路径用相对路径
- 配色不超过三种，不用阴影

样板见 `assets/deck-skeleton.html`。

**退出条件**：全部页面填完，无 `TODO` 残留。

### Step 5 · 溢出检查与交付

逐页检查：有没有文字超出画面、有没有一页塞了两件事、字号有没有低于下限、演讲者备注是不是每页都有。

**退出条件**：自检闸门全过。

## 自检闸门

交付前逐条打勾，**有一条不过就回退到对应步骤**：

- [ ] 页数在预算 ±10% 内　→ 不过回 Step 1
- [ ] 每页只讲一件事　→ 不过回 Step 2
- [ ] 单页正文 ≤60 字　→ 不过回 Step 4
- [ ] 正文 ≥24px、标题 ≥40px　→ 不过回 Step 4
- [ ] 讲师要说的话都在演讲者备注里，不在页面上　→ 不过回 Step 4
- [ ] 没有一页出现文字溢出　→ 不过回 Step 5
- [ ] 动作页写清了任务、时间、交付物　→ 不过回 Step 4
- [ ] 离线可用，或已明确告知现场需要网络　→ 不过回 Step 3
- [ ] 课件里没有学员名单与客户内部数据　→ 不过，立即改并向搭档报告

## 量化验收指标

| 指标 | 门槛 |
|------|------|
| 页数 / 分钟 | 0.8-1.2 |
| 单页正文字数 | ≤60 字 |
| 正文字号 | ≥24px |
| 标题字号 | ≥40px |
| 每页承载的概念数 | **1** |
| 有演讲者备注的页面占比 | **100%** |
| 溢出页数 | **0** |
| 配色数 | ≤3 |
| 占位图 / 图标堆砌 | **0** |
| 残留 `TODO` | **0** |

## 常见失败模式

| 失败 | 表现 | 怎么避免 |
|------|------|---------|
| 讲稿上屏 | 一页 200 字，讲师照着念 | 话进备注，页面留关键词 |
| 页数失控 | 60 分钟做了 120 页 | Step 1 先算预算 |
| 字号缩水 | 为了塞下内容把字改成 16px | 字号是硬下限，宁可拆页 |
| 图标堆砌 | 一排 emoji 冒充信息图 | 图要么是真结构图，要么不要 |
| 现场没网 | CDN 版在教室打不开 | 离线优先，降级要说清 |
| 动作页含糊 | "大家讨论一下" | 写清任务、时间、交付物 |
| 一页两件事 | 概念和案例挤在一页 | 拆 |
| 交付即失联 | 只给 HTML，改不动 | 同时交 `outline.md` |

## 降级与失败路径

**下载不到 Reveal.js**：用 CDN 引用版，交付时写明"现场需要网络"。两种都不行就交 `outline.md` 结构化大纲 + 每页文案，让搭档用手头任意工具装配。**这是合格交付，不是失败** —— 页面清单本来就是课件里最难的部分。

**搭档要 .pptx**：直说本技能出 HTML，做不了可编辑的 pptx。给两个选项：接受 HTML，或者交 `outline.md` 由他自己灌进 PPT 模板。**不要用改后缀、导出图片等方式假装交付了 pptx。**

**内容装不进时长**：把超出的部分单独列成"延伸材料"交给学员课后看，**不要在课件里保留讲不完的页** —— 讲师翻过去的每一页都在消耗信任。

**素材不足**：缺图的位置留空并在 `outline.md` 标注缺什么，不用占位图。占位图上台就是事故。

## 执行留痕与记忆写回

**留痕**：`outline.md` 与 `index.html` 一起留档。页面清单在，课件就能重做、能改、能复用到别的课；只留 HTML 等于交了一份改不动的东西。

**写回 `memory/YYYY-MM-DD.md`**：

1. 做了哪门课的课件、多少页、多长时间
2. Reveal.js 是离线版还是 CDN 版（下次不用重试）
3. **哪些页现场被跳过了**（这条最值钱 —— 反复被跳的页型说明设计冗余，下次直接不做）
4. 溢出检查发现的问题类型

**沉淀进 `MEMORY.md`**：本机是否已有 Reveal.js 离线副本及其路径、搭档的配色与版式偏好、每分钟实际讲多少页的真实数据。
