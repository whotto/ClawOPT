# 追问环节设计 · socratic-training-design

> 直接教是教不会的。学员不知道自己哪里不懂，以为懂的地方往往是最大的漏洞。
> 不暴露现状就注入新知识，像往满杯里倒水。

## 硬约束

1. **永远不设计"你错了"这句话。** 追问的全部技术就是让学员自己说出问题。**防御状态的人学不到东西。**
2. **场景必须三毒齐备**：信息噪声（来源互相矛盾）、时间压力（不能无限想）、代价非对称（做错的代价大于做对的收益）。三毒缺一就是糖水题，学员不会真调动思维。
3. **诊断题的选项之间不许有绝对对错。** 每个选项代表一种思维路径，评的是理由不是选择。
4. **烈度必须可调。** 每条追问链都要给出温和 / 中等 / 激烈三档，并写清什么信号下降档。**学员情绪崩了，环节就废了。**
5. **先设计退出，再设计追问。** 每一轮追问都要写清"学员说出什么就可以进下一轮"。未满足本步退出条件，不得进入下一步。

## 权限与数据边界

| 项 | 边界 |
|----|------|
| 读 | 本工作区 `memory/`、课程物料；联网公开案例 |
| 写 | 环节设计文档与本工作区 `memory/`；**不写入任何其他 Agent 的工作区** |
| 外发 | 无。不直接对学员发送任何内容 |
| 敏感数据 | 场景取材于真实公司时做脱敏；不把搭档客户的内部矛盾写成课堂案例 |
| 升权 | 不需要 `exec`、不需要 sudo、不安装任何包 |

## 何时使用 / 何时不用

| 场景 | 用不用 |
|------|--------|
| "设计一个让学员自己想明白的环节" | ✅ 用 |
| "这个互动环节每次都冷场" | ✅ 用（从 Step 4 切入救场） |
| "做一场 AI 决策模拟" | ✅ 用 |
| "出一道课前诊断题" | ✅ 用 |
| "生成整门课的物料" | ❌ → `course-material-pack` |
| "这个知识点怎么讲清楚" | ❌ 讲授型内容不走本技能 |
| "把追问链画成图" | ❌ → `mermaid-visual` |

**升级信号**：设计到一半发现学员连基础概念都没有 → 追问会变成羞辱，先补一段最小知识注入再回来。
**降级信号**：环节只有 10 分钟 → 只做一轮对立者，跳过放大者，直接接重构者。

## 输入输出契约

**输入**：训练目标（学员该改变的那个判断）+ 学员画像 + 环节时长
**输出**：一份《环节设计文档》，含 场景原文 / 诊断题与选项解读 / 三角色追问链（三档烈度）/ 观察要点 / 收尾话术 / 冷场预案
**上游**：`course-material-pack` 的模块目标；`point-intel` 的真实案例素材
**下游**：`course-material-pack` 的讲师手册第 4 段（追问话术）
**串联示例**：`course-material-pack`（定模块目标）→ `socratic-training-design`（设计追问链）→ 回填讲师手册 → `human-writing`（话术过一遍）

## 流程

### Step 1 · 锁定要撬动的那个判断

一个环节只撬一个判断。写成这句：**"学员进来时认为 [X]，出去时应该认为 [Y]。"**

**退出条件**：X 和 Y 都是具体的判断句，不是"提升 AI 思维"这类目标。**未满足本步退出条件，不得进入下一步。**
**常见失败**：一个环节想撬三个认知，追问链分叉，学员全程跟不上。

### Step 2 · 造场景（三毒齐备）

从搭档所在行业取材，改编真实案例。三毒逐条落实：

| 毒 | 怎么落 | 反例 |
|----|--------|------|
| 信息噪声 | 老板说做 A，用户要 B，数据显示 C | 只给一份干净的数据 |
| 时间压力 | "下周评审会要给方案" | "请充分思考后回答" |
| 代价非对称 | "判错半年白干，判对完成季度目标" | 做错了也没什么损失 |

**退出条件**：三毒逐条能指出在场景的哪一句话里。
**常见失败**：场景写得像教科书例题，条件清晰、答案唯一，学员两分钟就"做完了"。

### Step 3 · 出诊断题

选项之间没有绝对对错，每个选项背后是一条思维路径。题干后必问"你为什么这么选"。

**退出条件**：能为每个选项写出它代表的思维路径，且至少两个选项都说得通。
**常见失败**：藏了一个标准答案。学员一旦嗅到标准答案，就开始猜讲师想听什么，暴露环节立刻失效。

### Step 4 · 排三角色追问链

模板见 `assets/question-chain.md`。三个角色轮番上，不许串台：

| 角色 | 干什么 | 话术样式 |
|------|--------|---------|
| 对立者 | 给出完全相反的立场，逼他为自己辩护 | "我不同意。如果反过来看呢？" |
| 放大者 | 顺着他的逻辑推到荒谬处 | "那按你这个思路，所有情况都该这样？" |
| 重构者 | 承认对的部分，精准指出缺口 | "你说的没错，但还不完整。你到了 X 层，还差 Y 层。" |

**烈度三档**：

| 档 | 触发信号 | 节奏 |
|----|---------|------|
| 温和 | 学员信心低、情绪不稳、当众发言紧张 | 对立者 1 轮（用假设口吻）→ 直接重构者 |
| 中等 | 默认 | 对立者 1 轮 → 放大者 1 轮 → 重构者 |
| 激烈 | 学员经验足、态度笃定、明显轻敌 | 对立者 2 轮 → 放大者 2 轮 → 重构者 |

**退出条件**：每一轮都写清"学员说出什么就进下一轮"，且三档都写全。
**常见失败**：只写了中等档。现场遇到紧张的学员，讲师照着念就把人念崩了。

### Step 5 · 写收尾与冷场预案

收尾必须由学员自己说出改变了什么，**讲师不总结**。

冷场预案至少两条：点名先写完的人先讲 / 把问题降级成二选一举手 / 讲师先自曝一次自己判断错的经历。

**退出条件**：自检闸门全过。

## 自检闸门

交付前逐条打勾，**有一条不过就回退到对应步骤**：

- [ ] 一个环节只撬一个判断，X 和 Y 都写清了　→ 不过回 Step 1
- [ ] 三毒逐条能指到场景的具体句子　→ 不过回 Step 2
- [ ] 选项之间没有绝对对错　→ 不过回 Step 3
- [ ] 每个选项都写了它代表的思维路径　→ 不过回 Step 3
- [ ] 三角色不串台，各自话术分明　→ 不过回 Step 4
- [ ] 三档烈度全写了，降档信号写清了　→ 不过回 Step 4
- [ ] 每轮追问都有可判定的进阶条件　→ 不过回 Step 4
- [ ] 全文没有"你错了""这是不对的"　→ 不过回 Step 4
- [ ] 收尾是学员说，不是讲师总结　→ 不过回 Step 5
- [ ] 冷场预案 ≥2 条　→ 不过回 Step 5

## 量化验收指标

| 指标 | 门槛 |
|------|------|
| 一个环节撬动的判断数 | **1** |
| 场景三毒落实数 | **3/3** |
| 诊断题选项数 | 3-4，且 ≥2 个说得通 |
| 追问轮次 | 温和 2 轮 / 中等 3 轮 / 激烈 5 轮 |
| 直接否定句（"你错了"类） | **0** |
| 每轮追问的进阶条件 | **100%** 有 |
| 冷场预案条数 | ≥2 |
| 讲师在收尾环节的总结句数 | **0** |

## 常见失败模式

| 失败 | 表现 | 怎么避免 |
|------|------|---------|
| 糖水场景 | 条件清晰、答案唯一 | 三毒是硬约束 |
| 藏标准答案 | 学员开始猜讲师想听什么 | 选项无绝对对错 |
| 角色串台 | 对立者说着说着开始安慰人 | 三个角色分开写话术 |
| 只有一档烈度 | 遇到紧张学员照念，把人念崩 | 三档全写 + 降档信号 |
| 追问没有终点 | 追到学员沉默还在追 | 每轮写进阶条件 |
| 讲师抢答 | 学员刚要说，讲师先总结了 | 收尾归学员 |
| 羞辱式提问 | "这么简单都想不到？" | 铁律：不说你错了 |
| 用真实内部矛盾当案例 | 学员认出这是自己公司的事 | 取材脱敏 |

## 降级与失败路径

**现场学员明显崩不住**：立刻降到温和档，跳过放大者，重构者直接出场给肯定加补充。**环节的目的是暴露思维，不是击溃人。**

**没有合适的真实案例**：用搭档所在行业的公开事件改编，明确告诉学员"这是改编的真实事件"。**不要凭空编一个"某公司"** —— 编的场景没有毒性，学员一听就松劲。

**时间被压缩到 10 分钟**：只保留诊断题 + 对立者 1 轮 + 重构者。删掉的部分明确告诉讲师删了什么，不要让他以为这是完整设计。

**追问链设计不出来**：说明 Step 1 的那个判断还不够具体。回去把 X 和 Y 写成两句能对着念的话，再往下走。

## 执行留痕与记忆写回

**留痕**：环节设计文档保留"这个判断为什么值得撬"的一段说明，以及场景取材的来源与改编幅度。课后可对着它判断是设计问题还是执行问题。

**写回 `memory/YYYY-MM-DD.md`**：

1. 设计了什么环节、撬哪个判断
2. 用了哪档烈度、现场实际用的是哪档
3. **学员在哪一轮被问住了**（这条最值钱 —— 被问住的那一轮就是这条链的有效点，可以直接复用到别的课）
4. 冷场了没有、用了哪条预案

**沉淀进 `MEMORY.md`**：已验证有效的追问链清单（撬的判断 + 有效轮次），以及不同学员群体的默认烈度档位。
