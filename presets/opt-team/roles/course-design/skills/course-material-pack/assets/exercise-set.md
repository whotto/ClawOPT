# 学员练习册模板 · 四类练习

> 四类练习对应四个训练目的，顺序不能乱：
> 先暴露思维（不打分）→ 再对抗（出盲点）→ 再实战（有交付物）→ 最后迁移（换场景验证）。

## 类型 1 · 个人反思题（暴露思维路径，**不打分**）

```markdown
## 练习 1：你的第一反应（5 min，个人独立完成）

【场景】
<一段真实场景。信息互相矛盾、有时间压力、做错的代价大于做对的收益。>

【问题】
1. 你的第一直觉选哪个？（A / B / C / D）
2. 为什么这么选？（写 2-3 句）
3. 你对这个判断有多少信心？（低 / 中 / 高）

不要"想太多"，用第一反应。
```

**讲师用法**：本题不打分。统计全场选了什么，哪种思维模式最多。这个数据决定后面知识讲解的针对性。

## 类型 2 · 配对辩论题（对抗出盲点）

```markdown
## 练习 2：观点对抗（12 min，2 人一组）

【场景】
<一个真有争议的场景，两种立场都站得住。>

【规则】
1. 抽签决定立场，不许换
2. 各自准备 3 min，找 2 条支撑证据
3. 交锋 6 min，每人开口不超过 1 分钟
4. 最后 3 min，各自说一句对方哪里说得对

【交回】
你被对方说动的那一点是什么？
```

**讲师用法**：观察谁在辩护、谁在思考。抽签定立场是为了让人为自己不信的东西找理由，这一步才是出盲点的关键。

## 类型 3 · 小组实战题（有交付物）

```markdown
## 练习 3：动手做（25 min，4-5 人一组）

【任务】
<一个具体的、能在 25 分钟内做出东西的任务。>

【交付物】
一页纸，含：<字段 A> / <字段 B> / <字段 C>

【评分标准】
| 维度 | 2 分 | 1 分 | 0 分 |
|------|------|------|------|
| <维度一> | <可判定的描述> | | |
| <维度二> | | | |

【汇报】
每组 2 分钟，只讲结论和最大的分歧点。
```

**讲师用法**：评分标准课前就发给学员。让人知道往哪使劲，比事后打分有用。

## 类型 4 · 迁移应用题（换场景验证）

```markdown
## 练习 4：换个行业再来一次（15 min，个人）

【场景】
<与练习 3 底层同构、表层完全不同的场景。>

【问题】
1. 这个场景和刚才那个，本质上是同一类问题吗？
2. 你刚才用的方法，这里还成立吗？哪一步要改？
```

**讲师用法**：这是唯一能验证"学会了没有"的题。底层同构、表层异构是硬要求 —— 换个行业换套说法，方法还用得上，才算迁移成功。

## 出题红线

- 不出开放式空问（"你觉得 AI 能怎么帮你"），必须给场景和选项
- 不出有标准答案的知识题（那是考试不是训练）
- 场景必须真实，带公司、动作、数字、结果
- 练习总时长不超过模块时长的 60%，留出复盘时间
